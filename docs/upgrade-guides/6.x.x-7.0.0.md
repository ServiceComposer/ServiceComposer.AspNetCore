## EnableCompositionOverControllers() is removed

`EnableCompositionOverControllers()`, obsolete since 5.3.0 and a compilation error since 6.0.0, is removed. Code compiled against 6.x that still calls it fails with a `MissingMethodException`, instead of the `NotSupportedException` thrown by 6.x.

Call `WithCompositionOverControllers()` on the controller endpoints instead:

<!-- snippet: enable-composition-over-controllers -->
<a id='snippet-enable-composition-over-controllers'></a>
```cs
builder.Services.AddViewModelComposition();
builder.Services.AddControllers();

var app = builder.Build();
app.MapControllers()
    .WithCompositionOverControllers();
app.MapCompositionHandlers();
```
